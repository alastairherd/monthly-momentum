# Local Data Directory

This directory holds local working files that should **not** be committed to GitHub.

- `data/private/` — Personal holdings logs, ISA transaction records, broker exports, and Rule 6 top-10 tracking sheets (gitignored).
- `data/raw/` — Downloaded screener exports (e.g. Finviz or Market Chameleon CSVs) and raw market data files (gitignored).

Copy the header-only templates from [../templates/](../templates/) into `data/private/` or `data/raw/` before filling in real portfolio data.
